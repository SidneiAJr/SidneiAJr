## Projetos em Destaque

### 🌊 HydroRS — Monitoramento de Rios · 🏆 Indicado à LatinoWare
`Java/Spring Boot` `TypeScript/Express` `Python/FastAPI` `Redis` `MySQL` `JWT` `2FA` `Railway` `Vercel`

🔗 **[hydrorsweb.vercel.app](https://hydrorsweb.vercel.app/)**

Backend completo para monitoramento de níveis de rios em apoio à Defesa Civil do RS — duas stacks paralelas, dados em tempo real e segurança testada de verdade, não só no papel.

- Autenticação com matrícula + JWT + **2FA via TOTP** (Google Authenticator)
- Dados **ERA-5 Copernicus** com cache Redis — 17 variáveis climáticas da bacia
- Simulação hidrológica com 4 APIs de previsão + consenso multi-fonte
- Audit log completo com IP e geolocalização por ação
- Rate limiting, Helmet, Winston logging estruturado
- Testes de segurança: **SQLi, XSS, força bruta, headers** — todos aprovados
- Arquitetura em camadas: Controller → Service → Repository
